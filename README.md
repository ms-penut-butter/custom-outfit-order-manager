# Custom Outfit Order Manager

Custom Outfit Order Manager is a web app for designers to manage custom outfit
orders, customer details, body measurements, order items, delivery information,
payment status, and order progress from creation to completion.

This app is being built for my dad, who is a designer and business owner, to
help him manage customer orders more easily.

## Status

This project is a work in progress.

Currently being implemented:

- Persisting data to a database
- UI flows for managing customers and orders
- Automated tests
- Authentication

## Tech Stack

- Next.js
- React
- TypeScript
